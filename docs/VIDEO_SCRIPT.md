# QuoteLens — 90-second demo video script (~150 words)

> Read at a natural pace this runs ~90 seconds. Honest framing throughout:
> synthetic data, mock AI, human decides.

**[0–15s — the pain]**
"Every small shopkeeper knows this pain. Three supplier quotes on WhatsApp — a blurry photo, a PDF, a text message — and twenty minutes squinting to work out which one is actually cheapest. Meet QuoteLens."

**[15–45s — the demo]**
"Watch. Four AI agents read the quotes, convert every pack size — per-kilo, 25-kilo bags, 10-kilo packs — into one true per-unit cost, and rank them. It catches the traps: a minimum order you can't meet, a quote valid only two days, a low headline price hiding 18% GST."

**[45–70s — the human gate]**
"Here's the part that matters. The agent recommends — it never decides. Anything uncertain locks approval until a human confirms each flag, eyeball by eyeball. Only your tap generates the purchase summary and the audit trail."

**[70–90s — honest close]**
"Built for the shopkeepers who run India on WhatsApp. And we're honest about what this is: a working demo on synthetic data, with mock AI today and a slot for a real LLM tomorrow. QuoteLens — the agent compares, you decide."
